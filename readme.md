# KuranTeyit

KuranTeyit is a browser-based Quran study and research application built around Rashad Khalifa’s **Authorized English Translation**.

The project preserves the English source text exactly as provided while offering Turkish translations, comparative translations, word meanings, Quran topic maps, Arabic text comparison, verse notes, search tools, and research-oriented analysis features.

## Features

- Authorized English Translation as the primary reference
- Turkish translation displayed alongside the English text
- Arabic text and Turkish transliteration
- Comparison of multiple Turkish and English translations
- English-to-Turkish word tooltip dictionary
- Support for apostrophes, accented characters, initials, and hyphenated words
- Support for Quranic initials such as `A.L.M.*` and `A.L.M.S.*`
- Intelligent handling of long dashes without modifying the original English text
- Arabic word meanings, transliterations, and root information
- Verse-based footnotes
- Quran topic maps and related verse references
- Verse analysis panel
- Quran, translation, surah, and verse search
- Approximate search support for spelling variations
- Arabic verse audio playback
- Browser-based English text-to-speech
- Personal notes with Google Drive integration
- Multiple themes and font-size settings
- Responsive desktop and mobile interface
- Page caching and lazy-loaded data files
